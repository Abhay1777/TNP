# 44. FINAL SECURITY REVALIDATION

This is mandatory.

The backend MUST NOT trust the previous preview.

At confirmation:

1. Verify authentication.
2. Verify permission.
3. Verify ImportSession ownership.

* concurrent imports;
* manipulated requests;
